# Memory Pairs — Store Submission Materials

## Short description (CrazyGames / GameDistribution / itch.io)

Flip two cards and find every matching pair. Three board sizes, 24 adorable
icons, combo scoring with rising pitch, best-record saving. Easy to learn,
hard to master.

## Details

- Genre: Puzzle / Casual / Memory / Card
- Controls: Mouse / Touch (tap a card to flip). Keyboard: 1/2/3 pick a mode,
  Enter restarts, Esc returns to menu.
- Features: 3 difficulties (4×4 = 8 pairs, 6×6 = 18 pairs, 8×6 = 24 pairs),
  24 procedurally drawn icons, par-based scoring with ×1.5 speed bonus,
  combo bonus on consecutive matches, per-difficulty best records
  (fewest moves + fastest time), mute toggle, 3D flip animation and
  victory wave. Procedural graphics & sounds, single-file HTML5
  (no external assets), works offline once loaded.
- Tech: Vanilla JavaScript, Canvas, WebAudio. No frameworks, no tracking.
