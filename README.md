# Memory Pairs · Card Matching

Free single-file HTML5 memory game. Flip two cards at a time and find every
matching pair — three board sizes (4×4, 6×6, 8×6), 24 procedurally drawn
icons, combo scoring, best-record saving. One HTML file, zero assets.

**Play:** https://shuangyueliao.github.io/memory-pairs/

- Mouse / touch / keyboard (1/2/3 to pick a mode, Esc for menu)
- Procedural WebAudio sounds with rising combo pitch, mute toggle
- Procedural neon card backs and 3D flip animation, no dependencies
